# Examples

This directory contains example DESIGN.md outputs produced by the `aet-design-system-creation` skill.

## Example: SaaS Dashboard Design System

See `productivity-app-design-system.md` for a complete example of a DESIGN.md produced for a fictional productivity SaaS application. It demonstrates:

- **Dual-layer format**: YAML frontmatter with machine-readable tokens + markdown body with human-readable rationale
- **Token references**: Component tokens reference color, spacing, and rounded tokens (e.g., `"{colors.primary}"`)
- **Canonical section order**: Overview → Colors → Typography → Layout → Elevation & Depth → Shapes → Components → Do's and Don'ts
- **Aesthetic direction** tied to a memorable thing
- **Typography stack** (Space Grotesk + Inter) with token definitions
- **Color system** with semantic tokens and contrast rationale
- **Component tokens** with hover, active, and error variants
- **Accessibility and motion guidance**
