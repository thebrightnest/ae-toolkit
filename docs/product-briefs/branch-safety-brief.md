# Product Brief: Toolkit-Level Branch Safety

## Problem

The AET pipeline has a critical gap: `aet-ship` creates PRs but does not verify that commits actually land on `origin/main` before branches are deleted. Two completed feature branches were deleted after being "merged," but their commits never reached `origin/main`. A subsequent `git reset --hard origin/main` silently discarded the local merge commits, leaving ~20 hours of work as dangling commits recoverable only via `git fsck`.

## Status Quo Workaround

Users currently rely on `git branch -d`, which only checks if the branch is merged into **local HEAD**, not `origin/main`. Some projects have added project-level `AGENTS.md` rules and `.agents/commands/branch-cleanup.md` as temporary workarounds, but these are human-dependent and per-project.

## Target User

AET toolkit users running `aet-ship`, `aet-pipeline-implement`, or `aet-work` — especially those using AFK mode where branch cleanup happens automatically without human verification.

## Narrowest Wedge

Add automatic merge verification to three skills (~60 lines total):

1. `aet-ship` — halt with a clear warning if `git merge-base --is-ancestor HEAD origin/main` fails before branch deletion
2. `aet-pipeline-implement` — add a `merged` stage after `synced`, update the work queue with `merge_verified`
3. `aet-work` — check `merge_verified` on the previous task before starting the next

## Demand Evidence

- Real incident with recoverable data loss in the AET toolkit repo itself
- Downstream tasks were incorrectly blocked for days because upstream code appeared merged but was not on `origin/main`
- Manual git archaeology was required to reconstruct the work queue
- The report was auto-generated by `aet-evolve` retro + system-evolve cycle, meaning the system itself identified this as a recurring, high-leverage fix

## Verdict

**BUILD** — Strong demand evidence (real data loss), sharp wedge (three targeted skill changes), clear user (AET toolkit users), zero breaking changes, and high leverage (one fix improves every AET project simultaneously).
