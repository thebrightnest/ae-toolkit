# Upgrade from AE Toolkit v0.9.0 to v0.9.1

## Who needs to read this

- Anyone who installed AE Toolkit skills from the old `getatelier/ae-toolkit` repository.
- Anyone who ran `aet-setup` on a project before v0.9.1 and wants the new default reference docs.

## What changed

### 1. Correct repository URL

The README and installation examples now point to the correct repository:

```bash
# Before
npx skills add getatelier/ae-toolkit@<skill-name>

# After
npx skills add https://github.com/thebrightnest/ae-toolkit@<skill-name>
```

No code changes are required for existing installations, but new installs should use the updated URL.

### 2. Reference docs moved to `docs/references/`

`aet-setup` no longer scaffolds task-specific reference docs inside `.agents/reference/`. Instead, it creates them in `docs/references/`, which is visible to every agent that reads the project's root context file (`AGENTS.md`, `CLAUDE.md`, `.cursorrules`, etc.).

Files affected:

- `docs/references/README.md`
- `docs/references/testing-strategy.md`
- `docs/references/api-conventions.md`
- `docs/references/security-guidelines.md`
- `docs/references/ui-conventions.md`
- `docs/references/worktree-ship-hygiene.md`

The root agent-context file now contains a "Reference Docs (load on demand)" table pointing to these files.

### 3. New default reference templates

v0.9.1 ships opinionated starter reference docs distilled from four active AE Toolkit-consuming projects:

- **testing-strategy.md** — pyramid, suite splitting, overtesting rules, change-type validation matrix
- **api-conventions.md** — auth, response envelopes, URL naming, type-sync sequence
- **security-guidelines.md** — threat model, controls, forbidden patterns
- **ui-conventions.md** — component source priority, design-token alignment
- **worktree-ship-hygiene.md** — merge-base checks, rebase commands, PR scope red flags

### 4. `.gitignore` update

`aet-setup` now recommends ignoring `.agents/execution.log.jsonl` in addition to the existing patterns:

```gitignore
.agents/work-history.jsonl
.agents/execution.log.jsonl
aet-work.log
aet-work-*.log
```

## Upgrade steps

### Step 1: Re-install the skills

If you installed skills with `npx skills`, run the install commands again using the new URL:

```bash
# Re-install all AE Toolkit skills
npx skills add https://github.com/thebrightnest/ae-toolkit --all

# Or re-install a specific skill
npx skills add https://github.com/thebrightnest/ae-toolkit@aet-setup
```

Then refresh helper binaries on `PATH`:

```bash
~/.agents/skills/aet-setup/bin/install-aet-binaries
```

### Step 2: Update existing projects (optional)

For projects already set up with `aet-setup` before v0.9.1, you have two options:

#### Option A: Migrate reference docs to the new location

1. Move any existing `.agents/reference/*.md` files to `docs/references/`.
2. Update your root agent-context file (`AGENTS.md`, `CLAUDE.md`, etc.) to point to `docs/references/*.md` instead of `.agents/reference/*.md`.
3. If you do not have project-specific reference docs yet, run `/aet-setup` on the project and let it scaffold the new defaults in `docs/references/`.

#### Option B: Leave existing projects as-is

Existing `.agents/reference/` docs continue to work. New projects will use `docs/references/`. You can migrate incrementally when convenient.

### Step 3: Update `.gitignore`

If `aet-setup` generated your `.gitignore`, run `/aet-setup` again to add `.agents/execution.log.jsonl`. Alternatively, add it manually:

```gitignore
.agents/execution.log.jsonl
```

### Step 4: Verify

Run the project's validation:

```bash
make validate
```

Confirm:

- `docs/references/` exists with the expected files.
- The root agent-context file contains a "Reference Docs (load on demand)" table.
- `.gitignore` excludes `.agents/execution.log.jsonl`.

## Breaking changes

There are no runtime breaking changes in v0.9.1. The only structural change is the default location for reference docs created by `aet-setup`. Existing `.agents/reference/` docs remain functional.
