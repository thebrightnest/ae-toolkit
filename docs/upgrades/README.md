## Project upgrades

For upgrading an existing project that uses AE Toolkit skills, see [aet-work/references/upgrading-existing-project.md](../aet-work/references/upgrading-existing-project.md).

To re-run the setup scaffold on a project, invoke `/aet-setup` from your agent. It will audit the current state and propose only the changes needed to bring the project up to date.
