# Ticket 4: Port Phase 5 (Preview)

## Parent

[PRD: aet-design-system-creation Skill](../prds/aet-design-system-prd.md)

## What to Build

Port the preview phase from gstack's design-consultation. Generate an HTML preview page that visualizes the proposed design system (typography scale, color palette, spacing scale). Save to `docs/designs/DESIGN-preview.html`.

No external binaries required — pure HTML/CSS generated by the agent.

## Acceptance Criteria

- [ ] Skill generates `docs/designs/DESIGN-preview.html`
- [ ] Preview page includes:
  - [ ] Typography scale showing all font sizes with sample text
  - [ ] Color palette showing all colors with hex values
  - [ ] Spacing scale visualization
  - [ ] Sample components (button, card, heading) styled with the design system
- [ ] Preview page is self-contained (no external dependencies except possibly web fonts via CDN)
- [ ] Preview page renders correctly when opened in a browser
- [ ] If `docs/designs/` doesn't exist, skill creates it

## Blocked by

- Ticket 3: Port Phases 3–4

## Technical Notes

- Use inline CSS in the HTML file to keep it self-contained
- Font stack should use the proposed fonts (with system fallbacks if web fonts unavailable)
- Keep the HTML simple and clean — this is a reference, not a production page
- The preview is a validation tool: the user should look at it and say "yes, this feels right" or "no, the spacing is too tight"
