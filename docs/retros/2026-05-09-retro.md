# Retro: 2026-05-09

## What Happened

User asked to add worktree support to `aet-implement` and `aet-work`. Agent planned
an implementation using `EnterWorktree`, `ExitWorktree`, and `Agent` with
`isolation: "worktree"` — all Claude Code-specific tooling.

User interrupted mid-plan: "we need to upgrade this to not be Claude Code dependent."

Plan was discarded. `aet-discover` was run to reframe the problem. Second plan used
only `git worktree` commands — portable to any agent.

## What Was Wrong

The rule "never write skill instructions that assume a specific AI agent" already
exists in `AGENTS.md`. It was violated anyway.

## Root Cause

`skill-writing-guide.md` was not loaded before planning. Its quality checklist
includes "No agent-specific syntax" but it appears at the end, as a publish-time
gate. There is no pre-plan checkpoint.

The Shared Preamble collects `AGENTS_MD` presence and modification date, but does
not enforce reading its content. The critical guardrails went unread.

## Layer

`.agents/reference/skill-writing-guide.md` — missing pre-plan gate.

## Fix Applied

Added a **Pre-Plan Checklist** section to `skill-writing-guide.md` (top of file,
before any other guidance). Agent-agnostic check is item #1.

## Expected Prevention

Future sessions editing skills will hit the pre-plan checklist before designing
any solution, catching Claude Code-specific tooling at design time rather than
after the user interrupts.
